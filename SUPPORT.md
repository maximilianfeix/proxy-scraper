# Getting help

- **Questions and ideas:** ask in [GitHub Discussions](https://github.com/maximilianfeix/proxy-scraper/discussions).
- **Something broke:** open a [bug report](https://github.com/maximilianfeix/proxy-scraper/issues/new?template=bug_report.yml) with the command you ran and the output of `proxy-scraper --version`.
- **A proxy list is missing:** open a [new source](https://github.com/maximilianfeix/proxy-scraper/issues/new?template=new_source.yml) issue.
- **A security problem:** don't open a public issue – see [SECURITY.md](SECURITY.md).

Just need working proxies? The [live list](https://proxy-scraper.de/) is updated about every hour. Most questions about how the checks work are answered in the [FAQ](docs/faq.md) and in [check states](docs/check-states.md).
