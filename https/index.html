How do I get working HTTPS proxies in code or the terminal?

Without installing anything, download proxies.txt from this page. With the tool: pipx install proxy-scraper-cli, then proxy-scraper --pick 5 --https-only prints five from the hourly list. From Python, live_proxies() takes the same filters.
