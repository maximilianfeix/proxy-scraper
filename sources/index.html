How it's counted

About every hour each list is downloaded and its proxies are checked: a real HTTP, SOCKS4 or SOCKS5 handshake, a second request to another site that has to show the same exit IP, and a test page that has to arrive unchanged. "Passed every check" is the number of proxies from a source that got through all of that in an average recent run, "Share" is that number against the proxies checked from it.

A proxy that several lists carry counts for each of them. The files of one repository are one source. A run checks the most promising 150,000 candidates, so of a very large list only a part is checked each time. The lists published by proxy-scraper itself are left out: they are the result of these checks.

The same ranking from your own network: proxy-scraper --list-sources. A list is missing? Add it as a source.

Free proxies are run by strangers. Never send passwords or personal data through them. Collected and checked by proxy-scraper, open source, MIT licensed.
